# Story Fractal Weaver

esto pero que genere un visualizador fractal de la historia en terminos de estructuras y ritmo, debe ser como un mandelbrot pero ajustado a la historia. el fractal debe tener los nodos de arcanos, de personalidad, y los elementos arquetipicos del ritmo en la secuencia del circulo del heroe, cada parte del circulo es un mini circulo de 7 partes, siguiendo los chakras.y los 32 nodos de personalidad, que son 16 nodos base con su expresion activa o receptiva. es para obtener flujos fractales de historias ya terminadas. pero con infinitas posibilidades. dentro delas limitaciones de los parametros dados en un inicio.
